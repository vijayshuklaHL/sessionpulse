# Security

Session Pulse reads Claude Code transcripts, which can contain anything you've typed, so security reports matter.

**Please don't open a public issue for a vulnerability.** Instead, use GitHub's private reporting: the repository's **Security** tab → **Report a vulnerability**. Include what you found, how to reproduce it, and what an attacker could do with it. You'll get a reply within a week.

In scope: anything that lets another user, another website or another process on the machine read dashboard data, change to-dos, or run commands through Session Pulse.
